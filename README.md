# Campus Navigator

A static web app to search campus buildings and rooms and get walking directions.
No build step or dependencies. Open `index.html` to run it locally.

## Customise
Edit the data block at the top of `js/app.js`: junctions (`J`), roads (`E`), and buildings (`B`).

## Deploy on GitHub Pages
Settings > Pages > Deploy from a branch > `main` / `(root)`.
